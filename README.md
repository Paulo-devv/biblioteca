# Gerenciamento de Autores e Livros

Este projeto é uma API para gerenciamento de autores e livros, desenvolvida com **Node.js** e **Mongoose** para interagir com um banco de dados **MongoDB**.

## Tecnologias Utilizadas

- **Node.js** (runtime JavaScript)
- **Express.js** (framework web)
- **Mongoose** (ORM para MongoDB)
- **MongoDB** (banco de dados NoSQL)

## Funcionalidades

### Autores

- **Listar Autores**: Recupera todos os autores cadastrados.
- **Buscar Autor por ID**: Recupera um autor específico pelo ID.
- **Cadastrar Autor**: Adiciona um novo autor ao banco de dados.
- **Atualizar Autor**: Atualiza as informações de um autor existente.
- **Deletar Autor**: Remove um autor do banco de dados.

### Livros

- **Listar Livros**: Recupera todos os livros cadastrados.
- **Buscar Livro por ID**: Recupera um livro específico pelo ID.
- **Cadastrar Livro**: Adiciona um novo livro ao banco de dados.
- **Atualizar Livro**: Atualiza as informações de um livro existente.
- **Deletar Livro**: Remove um livro do banco de dados.
